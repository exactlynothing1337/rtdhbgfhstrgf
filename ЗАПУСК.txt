ЛПР 8, вариант 7 (Фитнес-клуб), N = 7: PORT 8107, ITEMS 6, CODE_L 3, CODE_D 5

В этом архиве НЕТ папки vendor (её нельзя скачать вне вашего компьютера), поэтому:

1. Положите папку проекта в домашнюю папку проектов OSPanel (domains) и при желании
   переименуйте в lpr-<ваш slug>.
2. Откройте консоль OSPanel в этой папке и выполните:
       composer install
3. Откройте файл .env и поправьте:
       APP_NAME="LPR <ваш slug>"
       LAB_STUDENT="Фамилия Имя"
       LAB_SLUG=<ваш slug>
       LAB_GROUP=<ваша группа>
       LAB_CODE=<код с доски>
   APP_KEY уже сгенерирован. Если Laravel пожалуется на ключ: php artisan key:generate
4. Запуск:
       php artisan serve --port=8107
   Откройте http://127.0.0.1:8107

В .env стоят SESSION_DRIVER=file и CACHE_STORE=file, чтобы форма и сообщения работали без базы
данных (база нужна только с ЛПР 9).

Git: выполните git init, укажите свои имя и почту и делайте коммиты по этапам из методички
(ЛПР8 п.1 ... п.6). История коммитов проверяется, одним коммитом всё не делайте.
Данные записей в app/Http/Controllers/CatalogController.php замените на свои.
